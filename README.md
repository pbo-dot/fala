# Fala

Lidt portugisisk fra Portugal til ferien, fem minutter om dagen. Til dig, der ikke er god til sprog.

- Fem minutter om dagen: hør, sig efter, og tryk "Kunne den" eller "Igen"
- Parlør med hverdagsord og situationer (café, restaurant, butik, find vej, hjælp)
- Om mig: præsentér dig selv med dine egne oplysninger
- Sig det for mig: skriv eller sig det på dansk, og få det på portugisisk

Udkast: `docs/forslag-fala.png` (endnu ikke bygget).
